## 📝 Descripción

En este repositorio se encuentran los trabajos, prácticas y modelos desarrollados durante el curso, utilizando algoritmos de aprendizaje supervisado para resolver problemas de clasificación y predicción.

Los modelos implementados permiten analizar el comportamiento de distintos algoritmos de *Machine Learning* mediante el uso de datasets reales y herramientas de análisis de datos.
